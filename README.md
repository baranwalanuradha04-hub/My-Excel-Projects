# My-Excel-Projects
# 📊 Excel Data Analysis Projects

A collection of Excel projects completed as part of my **Data Technician Bootcamp**, showcasing practical data analysis, reporting, and visualisation skills applied to retail and sales datasets.

## 🧰 Skills Demonstrated

### Formulas & Functions
- **SUM / SUMIF** – calculating totals and conditional totals (e.g. commission totals, sales by category)
- **AVERAGE / AVERAGEIF** – calculating overall and conditional averages (e.g. average student scores, average commission)
- **MAX** – identifying highest values (e.g. top scores, top sales)
- **DATE / MONTH / YEAR** – extracting and working with date components for time-based analysis
- **UNIQUE** – extracting distinct values from large datasets
- **VLOOKUP** – looking up and matching data across tables
- **SWITCH** – categorising data into custom groups (e.g. classifying products as *High*, *Medium*, or *Low* sales volume)

### Data Management
- Converting raw data ranges into structured **Excel Tables** (`Ctrl+T`)
- **Filtering** data by multiple criteria (e.g. largest to smallest, category-based)
- **Sorting** data to surface top performers and key trends
- **Conditional Formatting** to visually highlight highest/lowest values

### PivotTables & PivotCharts
- Building **PivotTables** to summarise large datasets by category, region, age group, and gender
- Creating **PivotCharts** (line, column, and pie charts) to visualise:
  - Revenue vs. profit trends over time
  - Product revenue by country
  - Revenue comparison by age group

### Data Visualisation
- Line charts for trend analysis
- Column charts for comparative analysis
- Pie charts for proportional breakdowns

## 📁 Datasets Used
- Retail sales dataset (transactions, customer demographics, commission)
- Student grades dataset
- Bike sales dataset (regional and demographic breakdowns)

## 🎯 Purpose
These projects were built to strengthen core Excel skills relevant to a **Data Technician** role, including data cleaning, analysis, and clear presentation of insights — skills that translate directly to tools like Power BI, Tableau, and SQL for further data analysis work.
